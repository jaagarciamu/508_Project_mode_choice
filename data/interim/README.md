# Datos intermedios locales

Contiene valores a nivel de registro e identificadores; se excluye de Git y no debe publicarse como producto analítico. Regenerar con `notebooks/04_mode_choice_join_preview.ipynb`. `mode_choice_trip_join_preview.csv` corresponde a la versión anterior de 33 filas y se conserva como referencia local anterior.
